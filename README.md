# LuCI App · 怀旧游戏（luci-app-game）

把路由器变成一台 **怀旧游戏站**：游戏放在路由器上，手机 / 电脑 / 平板打开浏览器就能玩。
客户端**不用装任何东西**，模拟器跑在浏览器里（WebAssembly），路由器零算力压力。

## ✨ 功能

### 页① 设置
| 功能 | 说明 |
| --- | --- |
| 插件开关 | 一键启用 / 停用 |
| 数据目录 | 游戏 / 封面 / 金手指 / 存档 统一存放，可指向大容量分区 |
| 上传游戏 | 流式上传（大文件不占内存），ZIP 自动解压归位 |
| 资源包本地化 | 一键把模拟器核心下载到路由器 → 内网闪电加载 + 断网也能玩 |

### 页② 游戏站（独立全屏页面）
| 功能 | 说明 |
| --- | --- |
| 游戏库 | 封面墙 · 平台筛选 · 搜索 · 最近游玩 · 收藏 |
| 右键菜单 | 重命名 · 收藏 · 删除 |
| 游玩 | 全屏 · 手机横屏 · 触摸虚拟按键 |
| 🪄 金手指 | RetroArch `.cht` 格式，面板内可增删 / 开关 |
| 💾 即时存档 | 存在路由器上，换台设备接着玩 |
| ⌨️ 键盘操作 | 插件快捷键 + 默认键位说明（支持自定义改键） |
| 🎮 手柄操作 | 即插即用（Xbox / PS / Switch），实时按键检测，支持双打 |

## 🕹 支持的机种

FC / SFC / GB / GBC / GBA / NDS / N64 / PS1 / MD / SMS / GG / SegaCD / 32X /
雅达利 2600·7800 / Lynx / PCE / 掌上蛇 / WonderSwan / Virtual Boy / 街机（MAME）

## 📦 安装

```sh
# 在 OpenWrt 源码树里编译
make package/luci-app-game/compile V=s

# 或在路由器上安装
opkg install luci-app-game_*.ipk
```

装好后：**LuCI → 服务 → 怀旧游戏**

## 📁 目录说明

| 目录 | 用途 |
| --- | --- |
| `roms/<平台>/` | 游戏文件（ZIP 会自动解压到这里） |
| `roms/bios/` | BIOS 文件（PS1 需要 `scph5501.bin`） |
| `covers/` | 封面图，与游戏同名（png / jpg / webp） |
| `cheats/` | 金手指 `.cht` 文件 |
| `saves/` | 即时存档 |
| `assets/` | 本地模拟器资源包 |

## 🎯 怎么放游戏

1. 页① 的「上传游戏」直接传（推荐，可整个 ZIP 丢进去）
2. 或用 SMB / SCP / SFTP 传进 `roms/<平台>/`

> 💡 封面：把同名图片放进 `covers/`，例如 `covers/超级玛丽.png`
> 💡 金手指：面板里直接加，或把现成 `.cht` 丢进 `cheats/`
